## Folder Structure Explanation

- **backend/**: This directory contains the source code of the project backend.
  - **src/**: All the logic for the backend contains here.
    - **controllers/**: All the business logic for apis.
    - **schemas/**: Defined all the schema used in db.
    - **index.ts**: Main file for backend
    - **server.ts**: Wrote server logic for express
- **frontend/**: This directory contains the source code of the project frontend.
  - **src/**: All the logic for the backend contains here.
    - **app/**: All the pages route for website.
    - **board/**: the chess board component.
    - **chess/**: the chess game component
    - **components/**: contains common components for website
    - **logics/**: contains chess logic
    - **square/**: contains square component
  - **public/**: All the website assets stays here.
  - **state/**: The react context api.
  - **utils/**: All the constants and api urls defined here.
- **docs/**: Documentation files are stored here.

Feel free to adjust this structure according to your project's needs and conventions.
