## Introduction

![Flexauth Twitter Post](https://github.com/abhijain1705/chess-game/assets/91758830/1f4c9b68-b931-4c89-a17e-03bbc5983dd3)
Chess.come clone is a multiplayer open source chess game that you can use to play in your free/busy\* time. Need to add a specific feature as you need? Change the code as you like and deploy it on your servers. Here is the most easy multiplayer game for all your needs.

Need some features you think might be helpful for others? Raise a PR and we will surely try to bring it live.
